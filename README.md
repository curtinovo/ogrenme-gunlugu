# ogrenme-gunlugu

Her gün öğrendiğim küçük şeyleri yazdığım kişisel günlük sitesi. GitHub'ı ve Claude ile çalışmayı öğrenmek için yapılan bir alıştırma projesi.

## Dosyalar

- `index.html`: Sitenin tek sayfası. Açık ve koyu temayı otomatik destekler.

## Yerelde görmek

`index.html` dosyasını çift tıklayıp tarayıcıda açmanız yeterli.

## Yayınlama

Repo ayarlarında **Settings → Pages** bölümünden `main` dalı seçilirse site `https://curtinovo.github.io/ogrenme-gunlugu/` adresinde yayınlanır.
